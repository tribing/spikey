# Contributing To Spikey

Thank you for helping make Spikey better.

Spikey accepts community Contributions through the Main Repository or directly through the Project Owners. Please read [LICENSE.md](LICENSE.md) before submitting anything.

## How To Contribute

- Open an issue for bugs, hardware notes, gameplay tuning, or feature ideas.
- Submit patches or pull requests to the Main Repository.
- Keep changes focused and easy to review.
- Include build notes or testing notes when possible.
- Preserve copyright notices, license notices, user-facing credits, and project identity markers.

## Contribution Terms

By submitting a Contribution, you agree that your Contribution is licensed under the terms in [LICENSE.md](LICENSE.md).

You also grant the Project Owners the right to use, modify, distribute, sublicense, commercialize, and relicense your Contribution as part of Spikey or related works.

Do not submit code, artwork, sounds, fonts, assets, or documentation unless you created them or have permission to contribute them under these terms.

## Forks And Redistribution

Public forks, mirrors, redistributed copies, rebranded versions, commercial versions, firmware images, binaries, kits, manufactured devices, and paid services based on Spikey are not allowed unless the Project Owners give prior written permission.

If a hosting platform requires a temporary technical fork to prepare a pull request, use it only for submitting that Contribution back to the Main Repository. Do not promote, release, distribute, sell, or maintain it as an independent version.
